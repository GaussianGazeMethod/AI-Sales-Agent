# AI agent销售助手

面向销售人员和管理人员的 B2B 销售展示项目。把自然语言沟通转成可追溯的客户事实、销售行动和阶段证据，覆盖「线索获取与验证」及「商机跟进与签单」两个闭环。

## 核心能力

- **AI 对话式录入**：整理线索和跟进事实，针对关键信息缺口追问，区分已执行、计划和待确认。
- **项目记忆与档案**：同客户多项目分别归档，保留事实来源、金额变化和需求报告版本。
- **阶段推进**：有效商机 → 客户触达 → 方案报价 → 预算确认 → 项目过会 → 招标采购 → 合同签约。执行层校验标准及证据，模型回复不能替代写入结果。
- **销售行动闭环**：诊断建议采纳为待办，执行后填写结果并关联跟进。
- **管理视角**：团队线索分配、项目评审、风险与卡单、漏斗、销售目标及周报。

AI 特色来自 Agently 工作流、业务 Skills、结构化输出和后端业务执行的配合。AI 调用失败会明确报错，不使用模拟回答伪装成功。

## 两种角色

| 账号 | 密码 | 范围 |
|---|---|---|
| sales | 123456 | 销售人员，维护本人客户、线索、商机和行动 |
| manager | 123456 | 管理人员，查看团队、分配线索及评审项目 |

内置三组完整合成案例：同客户多项目、直接采购及范围调整、分期建设与招标签约，共四个商机和两个练习线索。包含完整跟进、阶段证据、金额变化和两条签约结果。所有身份和演示联系ID均为虚构；预置依据不是模型回放或质量验证结果。

## 本地启动

需要 Python 3.12、Node.js 20+。在本目录运行，使用两个终端。

后端：

```bash
cd backend
python3.12 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python -c "import secrets; print(secrets.token_urlsafe(48))"
# 将生成值填写到 .env 的 SECRET_KEY。
uvicorn app.main:app --host 127.0.0.1 --port 8020
```

前端：

```bash
cd web
npm ci
npm run dev
```

打开 http://127.0.0.1:5230 ，点击演示销售或演示经理。接口文档在 http://127.0.0.1:8020/docs 。首次启动会自动建库并播种，重复启动保留演示操作。

也可在根目录先复制并配置 `backend/.env`，再用 `docker compose up --build` 启动后端；前端仍按上面的命令启动。Compose 使用独立的 showcase-data 卷。

## 启用 AI

在 `backend/.env` 填写自己的 `DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL`、`DEEPSEEK_MODEL` 后重启。模型名需与供应商账户及 `backend/SETTINGS.yaml` 中的思考等参数匹配。不提供公共密钥，调用费用由使用者承担。未配置密钥时可浏览和操作普通业务页面，AI 接口明确提示不可用。

可向助手输入：

> 帮我录入一条线索：演示学校丁，来源是市场活动，联系人为演示主任，职位是信息中心主任。

> 今天与演示学校丙的负责人电话沟通，客户希望做学生综合评价，具体预算来源还没确认，下周三准备演示。

随后查看项目档案、阶段证据和行动待办，再主动请求项目诊断或需求报告。

## 技术与目录

React 18 / TypeScript / Ant Design / Vite；FastAPI / SQLAlchemy / SQLite；Agently / 业务 Skills / YAML Prompts。

```text
backend/app/        API、业务服务、AI 协作与数据模型
backend/prompts/    结构化抽取、判断及报告提示词
backend/workflows/ AI 工作流及节点
spec/skills/       销售业务 Skills 及依赖资源
spec/doing/        展示版阶段与风险规则
web/src/           销售与管理界面
```

展示范围截止销售签约，未提供独立交付运营界面。签约依赖的共用合同、交接模型及服务保留。共用角色枚举保留，默认只初始化上述两个演示账号。

## 演示数据与配置

内置数据均为虚构演示样例。只将本目录内容上传为仓库根目录；`.env.example` 用于配置参考，`.env`、生成的数据库与上传附件保持忽略。

演示账号密码公开，项目按本地展示方式启动。公开部署前需调整账号和部署配置。自然语言输入及相关项目上下文会发送给配置的模型服务，请使用虚构演示数据。
