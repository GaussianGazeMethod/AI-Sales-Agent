4. [架构](../spec/doing/07-架构设计.md)、[AI 能力](../spec/doing/06-AI销售助手.md) 与 [编排](../spec/doing/23-AI助手编排技术设计与TDD实施顺序.md)。
5. [接口契约](接口说明.md) 和 [数据模型](../spec/doing/05-数据模型-表结构.md)。
6. [适配开发指南](适配开发指南.md)：修改行业、角色、阶段、模型或外部通道。
7. [43条业务用例](../spec/doing/24-AI助手TDD业务用例集.md) 与 `backend/tests`：核对变更影响。

## 功能覆盖检查

- 闭环一包括来源、四项录入、资料补充、实时查重、重复裁决、归属、指派改派、公海领取、验证、预约、工作日 SLA、回收、导入批次和来源指标。
- 闭环二包括七阶段、硬门槛、逐项证据、人工采纳、历史阶段、方案报价双条件、预算到合同的金额变化、采购路径、签约、行动反馈、丢单、风险、漏斗、评审、周报和目标。
- AI 包括五个业务 Skills、语义路由、限定节点、上下文预算、来源核对、多项目归属、金额核对、记录核对、版本、检查点、幂等与失败回执。

这些条目说明资料和实现覆盖面；不将合成预置数据或模型替身描述为真实模型端到端验证结果。具体限制保留在相应规则和适配文档中。
