# 08 · 场景与页面

## 1. 销售人员的工作路径

线索列表/AI 录入 → 联系与核实 → 有效商机 → 详情记录跟进 → 查看逐阶段证据 → 采纳候选和安排下一步 → 执行反馈 → 诊断/报告 → 采购与签约。

客户页按机构组织多个项目；项目详情保留各自事实、证据、行动和金额。手机文字对话复用同一账号和 API，不作为独立数据库。

## 2. 管理人员的工作路径

公海/导入批次 → 分配与改派 → 跟进时效和来源看板 → 团队商机漏斗 → 风险与卡单 → 项目评审/周会 → 目标和周报。

管理权限不等于系统管理员权限；当前两角色分发中不开放用户管理、规则发布和独立交付运营页面。

## 4. 页面级检查

- 线索表单核对四项信息、来源和查重，不因字段显示完整而跳过信息属实。
- 线索转商机后进入商机页面，线索历史保留入口和转化前事实。
- 商机步骤点击可查看历史依据，未进入阶段显示尚未开始，不伪造达成。
- 对话需要项目选择和实际回执，手机/PC 读到同一持久化状态。
- 行动反馈包括发生时间、方式和结果，完成后能回溯关联跟进。
- 报告可查看来源与版本，确认状态和草稿状态分开。
